## English

Quiz app by **CyberFirePulse** for trainings, instruction, demonstrations and workshops. Participants join with a group code from the trainer – no account needed. Without a group, free practice is possible.

- Active group at the top, quick switching between groups on the device
- Branding per group (title, logo, colours, badges), 11 colour themes, presentation mode
- Explanation per question or after discussion with the trainer
- Automatic updates via this repository (SHA-256 checked)

### Install

1. Click **Download** above and open the latest **CyberQuiz-v…** release.
2. Under **Assets**, tap `CyberQuiz-<version>.apk`.
3. Open the file; Android asks to allow installing from this source – choose **Allow**.

Managing quizzes, groups and scores is done with the **Cyber Quiz Beheer** Windows tool: https://github.com/cyberfirepulse/CyberQuiz

## Nederlands

Quiz-app van **CyberFirePulse** voor trainingen, instructies, demonstraties en workshops. Deelnemers doen mee met een groepscode van de trainer – zonder account. Zonder groep kan er vrij worden geoefend.

- Actieve groep bovenaan, snel wisselen tussen groepen op het toestel
- Huisstijl per groep (titel, logo, kleuren, badges), 11 kleurthema's, presentatiemodus
- Uitleg per vraag of na de bespreking met de trainer
- Automatische updates via deze repository (gecontroleerd met SHA-256)

### Installeren

1. Klik hierboven op **Download** en open de nieuwste release **CyberQuiz-v…**.
2. Tik onder **Assets** op `CyberQuiz-<versie>.apk`.
3. Open het bestand; Android vraagt om installeren vanaf deze bron toe te staan – kies **Toestaan**.

Quizzen, groepen en scores worden beheerd met de Windows-tool **Cyber Quiz Beheer**: https://github.com/cyberfirepulse/CyberQuiz
