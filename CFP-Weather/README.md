# CFP Weather

Android weather app in English and Dutch: current weather and a 7-day forecast for your favourite places or your GPS location, the coming hours (temperature, rain, wind), heads-up warnings and clothing advice, rain alerts in the background, a rain radar map and "Get outside": scores per activity (walking, running, cycling, dog walk, BBQ, photography, stargazing and more).

By **CyberFirePulse** · contact: cyberfirepulse@gmail.com

## Download

Get the APK from [Releases](https://github.com/cyberfirepulse/Android/releases) (tags `CFP-Weather-v…`).
Every release lists the SHA-256 of the APK. Check it on Windows with:

```
certutil -hashfile CFP-Weather-<version>.apk SHA256
```

On the phone: open the APK and allow installing from this source when Android asks. After that the app reports new versions itself (Settings ⚙️ → Check for updates).

## Data sources

Open-Meteo (weather, geocoding), RainViewer (rain radar), OpenFreeMap / OpenStreetMap (map).
