# Weer-Extremen

Android app for extreme weather and natural hazards: earthquakes, hurricanes, European weather warnings, named storms, volcanoes, floods, wildfires, tsunami bulletins, space weather and space objects (asteroids, fireballs, ISS). Dutch and English.

By **CyberFirePulse** · contact: cyberfirepulse@gmail.com

## Download

Get the latest APK from [Releases](https://github.com/cyberfirepulse/Android/releases) (tags `weer-extremen-v…`).
Every release lists the SHA-256 of the APK. Check it on Windows with:

```
certutil -hashfile Weer-Extremen-<version>.apk SHA256
```

On the phone: open the APK and allow installing from this source when Android asks. After that the app updates itself: it checks `update.json` in this folder, downloads the new APK, verifies the SHA-256 and starts the Android installer.
