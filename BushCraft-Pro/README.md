# BushCraft-Pro (Brander Bushcraft)

Android app for bushcraft and outdoor life in the Netherlands: compass and GPS, weather, edible and poisonous plants, mushrooms, animal tracks, trees, skills (fire, water, shelter, knots, first aid, navigation), bushcraft areas with an offline map, star map, SOS, plant recognition and a fishing screen with wind, water and rain radar for the place where you are. Dutch and English.

By **Brander Bushcraft** · published by **CyberFirePulse** · contact: cyberfirepulse@gmail.com

## Download

Get the APK from [Releases](https://github.com/cyberfirepulse/Android/releases) (tags `bushcraft-pro-v…`).
Every release lists the SHA-256 of the APK. Check it on Windows with:

```
certutil -hashfile BushCraft-Pro-<version>.apk SHA256
```

On the phone: open the APK and allow installing from this source when Android asks.

Ask for a trial or a licence by e-mail: cyberfirepulse@gmail.com (the app fills in your installation code).

The app stores only a random installation ID for the licence; no device ID, name or IP address.

## Data sources

Open-Meteo (weather, marine), RainViewer (rain radar), Kadaster / PDOK Top10NL and OpenStreetMap (water nearby), BigDataCloud (place name), Pl@ntNet (plant recognition), Wikipedia / Wikimedia Commons (photos).
